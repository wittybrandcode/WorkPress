## 🧭 1. الفلسفة المعمارية: التجريد الشامل للمجالات التجارية (Domain-Agnostic Engine)

لا تفرض منظومة **WorkPress** أي مسميات جامدة أو قطاع تجاري محدد؛ بل توفر محرك نماذج مجرد (Form Meta-Engine) يتيح لمدير النظام:
* إنشاء وتخصيص قوالب نماذج طلبات متعددة لأي قطاع (برمجة، استشارات، محاماة، تسويق، هندسة).
* تحديد الحقول المطلوبة وأنواعها والخيارات المتاحة لكل مجال.
* توليد واجهة النموذج للعميل في البوابة ديناميكياً بناءً على مخطط JSON المهيكل.
* تحويل الطلب فور اعتماده إلى مشروع رسمي متكامل يحمل بطاقة المواصفات الفنية المدخلة.

## ⚙️ 2. هيكل مخطط النماذج (JSON Intake Schema Format)

يتم تخزين وإدارة نماذج الطلبات في ووردبريس كـ JSON Schema مركزي في جدول الخيارات `workpress_intake_forms_schema`:

```json
{
  "general_request": {
    "title": "طلب مشروع عام",
    "description": "نموذج تقديم طلبات ومشاريع جديدة عامة",
    "icon": "dashicons-portfolio",
    "fields": [
      {
        "id": "target_audience",
        "label": "الجمهور والجهة المستهدفة",
        "type": "text",
        "required": true,
        "placeholder": "مثال: عملاء قطاع التجارة الإلكترونية"
      },
      {
        "id": "project_scope",
        "label": "نطاق العمل والمخرجات المطلوبة",
        "type": "textarea",
        "required": true,
        "placeholder": "اشرح باختصار أهم المخرجات المتوقعة..."
      },
      {
        "id": "priority_level",
        "label": "درجة الاستعجال",
        "type": "select",
        "options": ["عادي", "عاجل", "حرج"],
        "default": "عادي"
      }
    ]
  }
}
```

## 🎯 3. دورة حياة الطلب واستوديو الفرز الإداري (Triage Studio)

```
┌──────────────────┐      ┌──────────────────┐      ┌──────────────────┐      ┌──────────────────┐
│ 1. تقديم الطلب   │ ───► │ 2. قيد المراجعة  │ ───► │ 3. دراسة التسعير │ ───► │ 4. الاعتماد      │
│ (Client Portal)  │      │ (Triage Studio)  │      │ (Review Notes)   │      │ (Active Project) │
└──────────────────┘      └──────────────────┘      └──────────────────┘      └──────────────────┘
```

1. **التقديم المباشر (Submission):**
   - يقوم العميل بملء النموذج ورفع المرفقات والوثائق المساندة وتحديد الميزانية والتاريخ المستهدف.
   - ينشئ النظام كيان مشروع جديد برتبة `pending` ويربطه بحساب العميل.
2. **استوديو الفرز في لوحة التحكم (Triage Studio):**
   - يظهر تنبيه فوري للمدير وقادة المشاريع في غرفة العمليات.
   - يستعرض المدير بطاقة المواصفات الفنية، المرفقات، والميزانية المقترحة.
3. **خيارات القرار الإداري:**
   - **[ 🟢 قبول وتفعيل المشروع ]**: تحويل المشروع فوراً إلى حالة `active` وتعيين قائد المشروع للبدء في إنشاء مهام الكانبان.
   - **[ 🟡 قيد الدراسة والمفاضلة ]**: تحديث حالة الطلب إلى `under_review` مع كتابة ملاحظات للعميل وتحديث شريط المراحل لديه.
   - **[ 🔴 رفض أو اعتذار ]**: رفض الطلب مع تسجيل سبب الاعتذار المؤسسي.
