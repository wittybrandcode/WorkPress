الهيكلية المؤسسية 5-Tier Native Roles & Lifecycle

الهيكلية المعمارية للأدوار الخماسية ودورة حياة العمل

إسقاط ذري لأدوار ووردبريس الخمسة الأصلية على مراحل إدارة المشاريع، مع إمكانية التخصيص والاشتقاق الديناميكي

1. المدير العام (Administrator)

نظامي أصيل
administrator

الحوكمة الشاملة والسيادة: يملك حق الإشراف على كل المشاريع، تعيين قادة المشاريع، البت النهائي في طلبات الحذف، وإدارة مصفوفة الصلاحيات والإعدادات.

الصلاحيات التشغيلية الأساسية:

  • ✓ كامل الصلاحيات دون قيود (manage_options).
  • ✓ إدارة وتعديل مصفوفة الصلاحيات لجميع الأدوار.
  • ✓ البت في طلبات الحذف والنزاعات التشغيلية.
المسمى الافتراضي: مدير الموقع قابل للتخصيص (Alias)

2. المحرر (Editor)

نظامي أصيل
editor

القيادة والاعتماد (Project Lead): إنشاء المشاريع وإدارتها، إضافة وتخصيص الأعضاء، تكليف وتوزيع المهام، وسلطة اعتماد الحلول الرسمية لنقل المهام للاكتمال.

الصلاحيات التشغيلية الأساسية:

  • ✓ إنشاء وإدارة المشاريع (create/edit_projects).
  • ✓ إدارة أعضاء المشروع وتكليف المهام (assign_tasks).
  • ✓ مراجعة واعتماد الحلول الرسمية (accept_solutions).
التمثيل المقترح: مدير مشروع / قائد فريق قابل للتخصيص (Alias)

3. الكاتب (Author)

نظامي أصيل
author

التنفيذ والإنتاج المستقل (Core Specialist): عضو تنفيذي متفرغ في مشاريعه، يملك حق إنشاء مهام تشغيلية جديدة، تقديم المساهمات الفنية الحية، واقتراح الحلول.

الصلاحيات التشغيلية الأساسية:

  • ✓ إنشاء وتعديل مهام العمل (create/edit_tasks).
  • ✓ تقديم المساهمات والأدلة الفنية (add_contributions).
  • ✓ البحث في أرشيف المعرفة والاستفادة من الحلول.
التمثيل المقترح: موظف / مهندس / منفذ قابل للتخصيص (Alias)

4. المساهم (Contributor)

نظامي أصيل
contributor

المشاركة الموجهة (Collaborator / Freelancer): يشارك في المهام المسندة إليه حصراً، يقدم مساهمات وحلولاً ونقاشات للمراجعة، دون صلاحية إنشاء مهام مستقلة.

الصلاحيات التشغيلية الأساسية:

  • ✓ استعراض المهام المسندة له في مشاريعه فقط.
  • ✓ رفع المساهمات الفنية والحلول المقترحة للمراجعة.
  • ✓ لا يملك صلاحية إنشاء مهام جديدة من الصفر.
التمثيل المقترح: متعاون خارجي / متدرب قابل للتخصيص (Alias)

5. المشترك (Subscriber)

نظامي أصيل
subscriber

المتابعة والشفافية (Client / Stakeholder): وصول للقراءة فقط (Read-Only) للمشاريع والمهام المصرح له بها لمتابعة نسب الإنجاز وإبداء الملاحظات والاستفسارات.

الصلاحيات التشغيلية الأساسية:

  • ✓ قراءة المشاريع والمهام المصرح له بها.
  • ✓ إضافة ملاحظات واستفسارات مراجعة (Comments).
  • ✓ لا يملك صلاحية تعديل الحالات أو التكليف.
التمثيل المقترح: عميل / مراجع خارجي قابل للتخصيص (Alias)

🌱 اشتقاق الأدوار المخصصة

اشتقاق ديناميكي
custom_role_slug

التوسع والمرونة اللامحدودة: يتيح النظام لمدير الموقع إنشاء أدوار مخصصة جديدة مستنسخة من أي دور أصيل مع تخصيص الصلاحيات بالكامل وحفظها بأمان.

آلية الاشتقاق والحماية:

  • ✓ استنساخ فوري لكامل صلاحيات الدور المرجعي.
  • ✓ تعديل صلاحيات الدور المشتق عبر مصفوفة الصلاحيات.
  • ✓ إمكانية حذف الدور المشتق بأمان عند انتفاء الحاجة له.
متاح عبر تبويب: إدارة الأدوار إضافة دور جديد

المسار التشغيلي للمحطات السبعة

كل خطوة في دورة حياة العمل مع تفصيل كامل للأزرار والنوافذ التابعة لها

1

التنصيب والتهيئة التلقائية (Setup & Bootstrapping)

🔧 خلف الكواليس / تنشيط الإضافة

بمجرد تنصيب وتفعيل إضافة WorkPress في ووردبريس، يعمل محرك التثبيت الذكي تلقائياً دون تدخل يدوي:

📦 بنية البيانات الأصلية

  • ✓ تسجيل تصنيف المشاريع workpress_project
  • ✓ تسجيل نوع منشور المهام workpress_task
  • ✓ تسجيل نوع التعليق للمساهمات wp_contribution

🛡️ صمام الأمان وتأسيس الأنواع

  • ✓ إدراج نوع المساهمة المحمي general (عام 📌)
  • ✓ إدراج الأنواع الافتراضية (تنفيذ 🛠️، حل ⭐، مراجعة 🔍، نقاش 💭)
  • ✓ بناء جدول الإشعارات كـ Read Model حصري للقراءة السريعة.
2

لوحة الإعدادات وتخصيص بيئة العمل (System Settings)

📍 الصفحة: #/settings | الترس ⚙️

تضم صفحة الإعدادات قائمة جانبية بـ 7 تبويبات تمكّن الإدارة من تكييف المنظومة بالكامل مع أي نشاط:

مصفوفة الصلاحيات (Capabilities Matrix)

  • ✓ الأدوار الـ 5 الأصيلة: مدير (administrator)، محرر (editor)، كاتب (author)، مساهم (contributor)، مشترك (subscriber).
  • ✓ قائمة اختيار الدور وتعديل صلاحيات المشاريع، المهام، المساهمات، واعتماد الحلول.
  • ✓ مربعات تحديد فورية (Checkboxes) لضبط الصلاحيات ديناميكياً.
  • ✓ زر حفظ التعديلات لتطبيقها فوراً في قاعدة البيانات.

إدارة الأدوار والمسميات (Roles & Aliases)

  • ✓ جدول الأدوار المعيارية مع المسميات الظاهرية المخصصة (Aliases).
  • ✓ وسوم التمييز: نظامي محمي للأدوار الأساسية، و مخصص للأدوار المشتقة.
  • ✓ نموذج إنشاء دور اشتقاقي جديد مع استنساخ كامل الصلاحيات (Clone Permissions).
  • ✓ زر حذف الدور المخصص مع صمام تأكيد أمني.

🔄 أنواع المساهمات (Contribution Types)

  • ✓ تعديل أسماء وأيقونات (Emoji) الأنواع لتناسب قطاع العمل.
  • ✓ نموذج إضافة نوع مخصص جديد (Slug, Label, Emoji).
  • ✓ زر حذف النوع مع النقل الآلي لبياناته إلى نوع «عام».

👥 الأعضاء والتصدير (Members & Export)

  • ✓ جدول الأعضاء وتغيير دور أي مستخدم بنقرة زر.
  • ✓ تفضيلات التنبيهات بالبريد الإلكتروني.
  • ✓ زر تصدير النسخة الاحتياطية (JSON).
3

إدارة مساحات العمل والمشاريع (Projects & Privacy)

📍 الصفحة: #/projects | زر: + مشروع

استعراض المشاريع كبطاقات تفاعلية غنية بالمعلومات وضمان الخصوصية التامة بين الأقسام:

🎴 بطاقة المشروع (ProjectCard)

  • ✓ صورة الغلاف المخصصة للمشروع (Cover) أو نمط لوني جذاب.
  • ✓ شريط تقدم إنجاز المهام (Progress Bar) والنسبة المئوية.
  • ✓ صور الأعضاء المشاركين في المشروع (Members Avatars).

⚙️ خيارات المشروع وصمام الخصوصية

  • ✓ زر تعديل المشروع عبر ProjectModal.
  • ✓ زر أعضاء المشروع عبر ProjectMembersModal لمنع تسرب البيانات.
  • ✓ زر طلب حذف المشروع بنظام الحذف المسبب.
4

لوحة رادار الحقيقة (Truth-Driven Real-Time Kanban)

📍 الصفحة: #/kanban | زر: + مهمة

رادار الحقيقة الحية يعكس التقدم الواقعي للمهام أوتوماتيكياً استناداً إلى الأحداث الملموسة دون سحب وإفلات زائف:

📊 أعمدة رادار الحقيقة الأربعة

  • ✓ 🆕 جديدة / غير مسندة (New) - مهام مسجلة تنتظر تكليف الفريق (0 مكلفين | 0 مساهمات).
  • ✓ 👤 مسندة (Assigned) - مهام مخصصة لأعضاء وبانتظار أول مساهمة.
  • ✓ ⚙️ قيد الإنجاز (In Progress) - مهام تحتوي على مساهمات ونقاشات حية قيد العمل.
  • ✓ ✅ مكتملة ومعتمدة (Completed) - مهام أُثبت تنفيذها واعتمد القائد حلها رسمياً ⭐.

🎴 بطاقة المهمة والأزرار السياقية الذكية (TaskCard)

  • ✓ تتدرج البطاقة آلياً بين الأعمدة فور وقوع الحدث (تكليف ➔ مساهمة ➔ اعتماد).
  • ✓ زر سياقي في "جديدة": + تخصيص عضو 👤 عبر TaskAssignmentModal.
  • ✓ زر سياقي في "مسندة": + بدء مساهمة ✍️ عبر ContributionModal.
  • ✓ زر سياقي في "قيد الإنجاز": ⭐ مراجعة واعتماد الحل.
5

تفاصيل المهمة وتوثيق المساهمات (Task Detail & Timeline)

📍 الصفحة: #/tasks/:id | زر: + مساهمة

المساحة المتكاملة لتنفيذ العمل، تبادل المرفقات، وسجل التدقيق الزمني الشفاف:

📝 تفاصيل المهمة والتحكم

  • ✓ محتوى المهمة المنسق، صورة الغلاف، وشريط المكلفين.
  • ✓ زر إغلاق المهمة (Close Task) لحمايتها من التعديل.
  • ✓ زر إعادة فتح المهمة (Reopen) للمدير.

💬 الخط الزمني للمساهمات والإجراءات

  • ✓ رفع غلاف مخصص للمساهمة عبر ImagePicker.
  • ✓ زر ⭐ اعتماد كحل مقترح (Accept).
  • ✓ زر 🗑️ طلب حذف مساهمة مع ذكر السبب.
  • ✓ صندوق إضافة مساهمة مدمج في أسفل الصفحة بمحرر غني.
6

لوحة المساهمات وشريط الفلترة المتقدم (Contributions Grid)

📍 الصفحة: #/contributions | شريط الفلترة الثابت

شريط فلترة ثابت لا يتأثر بالتمرير يوفر استقصاء وتصفية شاملة لكل أعمال الفريق:

🔍 أدوات الفلترة الذكية (Sticky Bar)

  • ✓ فلتر المشروع: تصفية مساهمات مشروع محدد.
  • ✓ فلتر المهمة: تصفية بمهام المشروع المختار.
  • ✓ فلتر النوع: تصنيف بالأنواع المخصصة أو سجلات النظام.
  • ✓ فلتر الحالة: (الكل / ⭐ معتمد كحل / ⏳ قيد المراجعة).
  • ✓ فلتر الكاتب: تصفية المساهمات بحسب صاحبها.

⚡ البحث المباشر وإعادة الضبط

  • ✓ صندوق البحث الفوري: بحث نصي ذكي مع Debounce.
  • ✓ زر إعادة ضبط الفلاتر 🔄 بنقرة واحدة.
  • ✓ زر معاينة تفصيلية عبر ContributionDetailModal.
7

⭐ الاعتماد والتحول المعرفي والاكتمال المتسلسل (Cascading Completion)

📍 الصفحة: #/knowledge | زر: ⭐ اعتماد كحل

تتويج الحلول الممتازة بحوكمة صارمة وسلسلة تفاعلات متزامنة تقود لاكتمال المهمة والمشروع ودخول المعرفة:

👑 حوكمة الاعتماد (Lead/Admin)

  • ✓ زر الاعتماد متاح حصرياً للمدير العام ومدير المشروع المكلف.
  • ✓ قفل المساهمة المعتمدة من التعديل لحماية الأثر المعرفي.
  • ✓ إلغاء الاعتماد يعيد المهمة لـ "قيد المراجعة 🔍" ويعيد فتح المشروع.

🔄 دورة الاكتمال المتسلسل (Cascading Flow)

  • ✓ اعتماد المساهمة: يؤدي تلقائياً إلى اكتمال المهمة وإغلاقها.
  • ✓ اكتمال كل المهام: يؤدي تلقائياً إلى اكتمال المشروع بالضرورة (100%).
  • ✓ ظهور الحل المعتمد فوراً في أرشيف المعرفة مع سياق مشكلته ومرفقاته.

فهرس النوافذ المنبثقة وصمامات الأمان

مرجع سريع لكافة النوافذ التفاعلية والأزرار التي تفتحها

النافذة المنبثقة (Modal) الزر الذي يفتحها الوظيفة وصمام الأمان
ProjectModal زر + مشروع في الشريط العلوي أو بطاقة المشروع إنشاء أو تعديل مشروع (الاسم، الوصف، اللون، صورة الغلاف عبر ImagePicker).
ProjectMembersModal خيار أعضاء المشروع من بطاقة المشروع تحديد أعضاء المشروع لمنع تسرب البيانات وضمان الخصوصية التامة.
TaskModal زر + مهمة في الشريط العلوي إنشاء/تعديل مهمة (المشروع، الأولوية، الغلاف، محرر النصوص الذكي).
TaskAssignmentModal زر 👤 تكليف على بطاقة المهمة أو صفحتها اختيار وتكليف المسؤولين عن تنفيذ المهمة من بين أعضاء المشروع.
ContributionModal زر + مساهمة في الشريط أو على المهمة إدخال مساهمة، اختيار نوعها الديناميكي، رفع غلاف مستقل، والمرفقات.
ContributionDetailModal زر معاينة في صفحة المساهمات قراءة نص المساهمة كاملاً، عرض غلافها ومرفقاتها وسجل اعتمادها.
TaskQuickPreviewModal زر 👁️ معاينة سريعة في لوحة الكانبان استعراض محتوى المهمة وخطها الزمني فوراً دون مغادرة شاشة الكانبان.
ConfirmModal أزرار الحذف (مشاريع، مهام، مساهمات) صمام أمان يتطلب تأكيد الحذف مع كتابة سبب الحذف (Reason) لأرشفته.
NotificationsDrawer جرس 🔔 التنبيهات في الشريط العلوي درج جانبي متحرك يعرض التكليفات والأنشطة الجديدة مع زر "تحديد كمقروء".
