تجريد كامل للحقول (Complete Field Abstraction)

لا يفرض النظام مسميات ثابتة؛ بل يحدد المدير مسمى حقل العنوان، حقل الوصف، والحقول التخصصية بحسب نشاط المنشأة.

🏛️

الطلب مشروع كامل (CPT_PROJECT)

ينشأ الطلب ككيان مشروع رسمي وليس مهمة فرعية، موسوماً بحالة `is_client_request` لمراجعته وتوزيع مهامه.

💡

عنوان ذكي باقتراحات مسبقة + كتابة حرة

قائمة خيارات سريعة شائعة تسرع على الزبون الاختيار مع مرونة تامة لكتابة عنوان مخصص في أي لحظة.

📦

خزينة المواصفات المهيكلة (Specs Vault)

تُحفظ كافة الخانات التي عبأها العميل بصيغة JSON مهيكلة لتعرض للمدير وفريق العمل بمسمياتها الأصلية.
