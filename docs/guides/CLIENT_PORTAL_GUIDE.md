## 🧭 1. الفلسفة المعمارية للبوابة (Zero CSS Bleed Architecture)

تم تصميم **بوابة المستفيدين (WorkPress Client Portal)** لتكون مساحة مستقلة 100% داخل الإضافة ومفصولة تماماً عن ثيم الموقع:

1. **الاستقلالية التامة (Standalone Canvas Endpoint):**
   - تعمل البوابة عبر مسار مخصص `/portal/` يتم اعتراضه وتحميله عبر `template_include` دون استدعاء هيدر أو فوتر قالب ووردبريس (Zero Theme CSS Bleed).
   - توفر تجربة تشبه أرقى تطبيقات الـ SaaS الحديثة المستقلة مع زوايا حادة مؤسسية (`border-radius: 0 !important;`) وخط كايرو الموحد (`Cairo`).
2. **عزل الصلاحيات وحظر التكليف (Assignment Isolation):**
   - يُمنع تكليف حسابات العملاء (`workpress_client`) بأي مهام في الكانبان أو إدراجهم في مسارات العمل الداخلية للفريق الفني.
3. **نطاق الرؤية المزدوج والتحول المعرفي (Visibility Scope & Synapses):**
   - يرى العميل فقط المساهمات والمخرجات المعتمدة (`client_review` / `approved deliverables`).
   - كل تفاعل من العميل (ملاحظة، طلب تعديل، مصادقة) يُسجل تلقائياً كـ `Contribution` موثقة في الذاكرة المؤسسية.

## 🏗️ 2. الهيكل البصري والمكونات التفاعلية الرئيسية (Portal V2.2)

```
┌────────────────────────────────────────────────────────────────────────┐
│  💎 3-Tier Sticky Header: Institutional Brand + Context + Actions    │
├────────────────────────────────────────────────────────────────────────┤
│  ⚡ Top KPI Ribbon: Projects, Deliverables, Progress %, Total Requests │
├────────────────────────────────────────────────────────────────────────┤
│  🎯 Status Filter Tabs: [جميع المشاريع] [قيد التنفيذ] [قيد الدراسة] [المكتملة] │
├────────────────────────────────────────────────────────────────────────┤
│  🖼️ Wide Compact Portfolio Grid with Smart Generative SVG Covers       │
│    • Icon-Only Action Buttons (.btn-portal-icon) with Tooltips         │
│    • Compact Meta Pills (Lead, Due Date, Deliverables Count)           │
├────────────────────────────────────────────────────────────────────────┤
│  🔢 Modern Tabular Bottom Pagination (< 1 2 3 ... 7 8 >)               │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. الهيدر المؤسسي الثابت ثلاثي الطبقات (`Sticky 3-Tier Header`):
- **الشريط العلوي (Brand Ribbon)**: شعار WorkPress، مساحة المستفيد، ومؤشر الاتصال اللحظي.
- **الشريط الأوسط (Context & Quick Actions)**: بطاقة البروفايل، الرتبة، وزر تقديم الطلبات السريع `[+]`.
- **الشريط السفلي (Navigation Tabs & Project Switcher)**: التبديل بين (الرئيسية، سجل طلباتي، محفظة المشاريع، خزانة المخرجات المعتمدة).

---

### 2. محرك الصور الافتراضية التوليدي الذكي (`Smart Generative Vector Covers`):
- في حال عدم توفر صورة غلاف مخصصة للمشروع أو الطلب أو المخرج، يقوم المحرك المركزي (`renderCardCover`) في `portal-core.js` بتوليد **غلاف متجهي SVG ذكي** تلقائياً:
  - تدرجات لونية مؤسسية منسقة (Emerald, Indigo, Slate, Amber, Sky).
  - أشكال هندسية رقمية ديناميكية وأيقونة دلالية مستمدة من نوع العنصر وحالته.
  - باركود ومعرّف رقمي موثق (`#PRJ-730`, `#REQ-120`).

---

### 3. أزرار فلاتر دورة الحياة السريعة (`Status Filter Tabs`):
- تعلو شبكة المشاريع في الصفحة الرئيسية وتتيح الفلترة المباشرة بخط كايرو وزوايا حادة:
  - **جميع المشاريع (`All`)**: إجمالي المحفظة.
  - **قيد التنفيذ والإنجاز (`In Progress`)**: المشاريع النشطة الجارية.
  - **قيد الدراسة والانتظار (`Pending / Review`)**: المشاريع قيد المراجعة الفنية.
  - **المعتمدة حديثاً (`Approved`)**: المشاريع المصادق عليها حديثاً.
  - **المكتملة والمنجزة (`Completed`)**: المشاريع المنتهية بالكامل.
- مزودة بشارات أرقام ديناميكية مع **إعادة ضبط الترقيم التلقائي** للصفحة الأولى فور التبديل.

---

### 4. بطاقات المشاريع العريضة والمدمجة (`Compact Portfolio Cards`):
- **عرض مريح ومتسع**: `minmax(360px, 1fr)` مع فجوة تنفسية `1.75rem`.
- **تصميم مدمج بدون حشو**: حذف نصوص الشرح الطويلة والتركيز على المؤشرات التنفيذية.
- **أقراص البيانات المصغرة (`Meta Pills`)**:
  - المسؤول الفني: `<i class="dashicons dashicons-admin-users"></i>`
  - موعد التسليم: `<i class="dashicons dashicons-calendar-alt"></i>`
  - المخرجات الفنية: `<i class="dashicons dashicons-portfolio"></i>`
- **أزرار الأيقونات النظيفة (`.btn-portal-icon`)**:
  - زر الدخول لمساحة العمل: `<i class="dashicons dashicons-arrow-left-alt2"></i>` مع تلميح `title`.
  - زر وثيقة الاستلام الرسمية (عند اكتمال المشروع): `<i class="dashicons dashicons-media-document"></i>`.

---

### 5. نظام الترقيم الحديث بالأرقام والأسهم (`< 1 2 3 ... 7 8 >`):
- **خط رقمي حديث**: استخدام خط لاتيني عريض (`Plus Jakarta Sans / Modern Tabular`) للأرقام لمنع تشوه الأرقام.
- **أسهم فقط بدون كلمات**: استبدال كلمتي "السابق" و "التالي" بأسهم اتجاهية دقيقة.
- **نافذة النقاط الذكية (`Smart Ellipsis Window`)**: توليد تلقائي لعلامة `...` عند تعدد الصفحات (مثال: `< 1 2 3 ... 7 8 >`).

---

### 6. خزانة المخرجات والمصادقة والتوقيع الرقمي (`Deliverables Vault & Sign-off`):
- استعراض المخرجات الفنية والحلول المعتمدة مع إمكانية تحميل الملفات.
- **التوقيع الرقمي المشفر بـ SHA-256**:
  - عند مصادقة العميل، يتم توليد بصمة رقمية مشفرة تحوي: `SHA256(Project_ID + Client_User_ID + Timestamp + Nonce)`.
  - توليد وثيقة الاستلام الرسمية التنفيذية مع خيار الطباعة والتصدير.
