## 🧭 1. الفلسفة المعمارية للبوابة (Zero CSS Bleed Architecture)

تم تصميم **بوابة المستفيدين (WorkPress Client Portal)** لتكون مساحة مستقلة 100% داخل الإضافة، مع تطبيق المبادئ التالية:

1. **الاستقلالية التامة (Standalone Endpoint):**
   - تعمل البوابة عبر مسار مخصص `/portal/` يتم اعتراضه وتحميله عبر `template_include` دون استدعاء هيدر أو فوتر قالب ووردبريس (Zero Theme CSS Bleed).
   - توفر تجربة تشبه تطبيقات الـ SaaS الحديثة المستقلة.
2. **عزل الصلاحيات وحظر التكليف (Assignment Isolation):**
   - يُمنع تكليف حسابات العملاء (`workpress_client`) بأي مهام في الكانبان أو إدراجهم في مسارات العمل الداخلية للفريق الفني.
3. **نطاق الرؤية المزدوج (Visibility Scope):**
   - يرى العميل فقط المساهمات والمخرجات المعتمدة (`client_review`)، بينما تظل المسودات الهندسية الداخلية محجوبة وآمنة.

## 🚀 2. مكونات وأقسام مساحة العميل

```
┌────────────────────────────────────────────────────────────────────────┐
│                      WorkPress Standalone Portal                       │
├───────────────────┬────────────────────┬───────────────────────────────┤
│ 🚀 مشاريعي الجارية │ 📋 طلباتي ومقترحاتي │ 🏆 مخرجاتي المعتمدة والتوقيع  │
├───────────────────┼────────────────────┼───────────────────────────────┤
│ • شريط نبض الإنجاز │ • مسار الفرز الآلي │ • مراجعة الحلول والمرفقات     │
│ • المعالم والتواريخ│ • الميزانية والوقت │ • التوقيع الرقمي بـ SHA-256   │
│ • قنوات التنبيه   │ • الملاحظات الفنية │ • تنزيل وثيقة الاستلام PDF    │
└───────────────────┴────────────────────┴───────────────────────────────┘
```

### 1. تبويب مشاريعي الجارية (Active Projects):
* يعرض بطاقات المشاريع المعتمدة النشطة الخاصة بالعميل.
* شريط نسبة الإنجاز التلقائي (Progress Bar) وتاريخ التسليم المستهدف.
* الوصول لغرفة تفاصيل المشروع ومتابعة المعالم والمخرجات.

### 2. تبويب طلباتي ومقترحاتي (Pending Requests):
* عرض الطلبات المقدمة عبر نماذج الاستقبال الديناميكية ومتابعة مؤشر الفرز (`Stepper`):
  1. `قيد المراجعة والدراسة (Under Review)`
  2. `إعداد عرض العمل والميزانية (Quotation)`
  3. `الموافقة والبدء الفعلي (Approved & Active)`
* بطاقة المواصفات الفنية والميزانية المقترحة والمرفقات المرفوعة.

### 3. تبويب المخرجات المعتمدة والتوقيع الرقمي (Deliverables & Sign-off):
* استعراض الحلول الهندسية التي اعتمدها مدير المشروع للمراجعة النهائية.
* إمكانية تحميل المرفقات والاطلاع على تفاصيل الحل.
* **زر [ 🏆 اعتماد واستلام المشروع النهائي ]**:
  - يتيح للعميل توثيق استلامه للمشروع رسمياً.
  - يقوم النظام بختم التوقيع ببصمة مشفرة `SHA-256 Timestamp Fingerprint` غير قابلة للتزوير وتوليد وثيقة الاستلام الرسمية.

## ⚙️ 3. التثبيت والتهيئة وShortcodes

### التضمين عبر الكود القصير (Shortcode):
يمكن تضمين البوابة في أي صفحة داخل ووردبريس باستخدام الكود القصير:
```text
[workpress_client_portal]
```

### التوجيه الذكي فور تسجيل الدخول:
تقوم خدمة المصادقة `WorkPress_Auth_Service` بتوجيه أي مستخدم برتبة `workpress_client` تلقائياً إلى `/portal/` فور تسجيل دخوله عبر `/workpress-login/` لمنع وصوله للوحة التحكم الإدارية `/wp-admin/`.
